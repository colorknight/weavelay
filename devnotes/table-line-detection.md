# 表格线检测参数

## 流程

```
灰度图 → OTSU二值化 → 膨胀(1×7)填细线断点 → 开运算(1×70)去文字 → 投影(1%阈值) → 合并(20px)
```

## 关键参数 (TableBorderDetector.java)

| 步骤 | 竖线参数 | 横线参数 |
|------|---------|---------|
| 二值化 | `THRESH_BINARY_INV \| THRESH_OTSU` (无高斯模糊) | 同 |
| 膨胀填洞 | kernel `Size(1, 7)` | kernel `Size(7, 1)` |
| 开运算去字 | kernel `Size(1, max(rows/10, 70))` | kernel `Size(max(cols/10, 70), 1)` |
| 投影阈值 | `max(rows * 0.01, 2)` | `max(cols * 0.05, 2)` |
| 合并间距 | `MERGE_GAP = 10` | 同 |

## 为什么有效

- **OTSU**: 白底黑线表格，二值化效果完美
- **不开高斯模糊**: 防止1px细线被模糊吃掉
- **膨胀1×7**: 填1-2像素的微小断点，线连上了但字连不上(字不够长)
- **开运算1×70**: 线从头贯穿到底，70px核蚀不掉；文字三四十px，直接被蚀光
- **1%阈值**: 开运算后只剩线，极低阈值确保细线不丢
- **20px合并**: 近邻线合成一条

## OCR碰撞

线检测返回空格子 → `buildCellGrid` 用 OCR 中心点碰撞填文字 (快，一次OCR)
