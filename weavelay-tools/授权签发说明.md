# 织版 Licence 签发说明

厂商内部使用。私钥和本目录不要放进客户便携包。

## 默认规则

**不写期限时，按 365 天签发。** 从签发时刻起算，到期后客户机无法确认写入、写出 Excel、导入/导出模板包。

客户设置 → Licence 会显示「有效至 yyyy-MM-dd」。到期需重新签发并让客户再导入一次。

授权绑机器指纹，拷到别的电脑无效。

## 客户要提供什么

让客户打开织版 → **设置 → Licence**，点「复制指纹」，把整段 **64 位十六进制机器指纹** 发给你。

不要用短的 request code 签发。

## 怎么签发（推荐 PowerShell）

在工程根目录执行。第一次会编译，大约一分钟。

**一年（默认，可省略 `-Days`）：**

```powershell
.\weavelay-tools\issue-license.ps1 -MachineId <64位指纹> -Out 某某厂.weavelaylic -Customer 某某厂
```

**试用 90 天：**

```powershell
.\weavelay-tools\issue-license.ps1 -MachineId <64位指纹> -Out 试用.weavelaylic -Customer 某某厂 -Days 90
```

**指定截止日期（含当天）：**

```powershell
.\weavelay-tools\issue-license.ps1 -MachineId <64位指纹> -Out 年约.weavelaylic -Customer 某某厂 -Until 2027-03-31
```

**永久（必须显式声明，不是默认）：**

```powershell
.\weavelay-tools\issue-license.ps1 -MachineId <64位指纹> -Out 永久.weavelaylic -Customer 某某厂 -Perpetual
```

`-Days` 与 `-Until` 不要同时用。文件默认写到 `weavelay-tools\issued\`。

## 客户怎么导入

把 `.weavelaylic` 发给客户。客户在 **设置 → Licence** 点「导入 licence 文件」，选这个文件。成功后状态为「已授权」，并显示到期日。

过期后同样入口再导入新文件即可，不必重装软件。

## 批处理

```bat
weavelay-tools\issue-license.bat <机器指纹> [文件名] [客户名] [天数]
```

第四参数省略则为 **365 天**。永久授权把第四参数写成 `perpetual`。按日历截止日期请用上面的 PowerShell `-Until`。

## 不要发给客户的东西

- `weavelay-tools\keys\private.ed25519.b64`（私钥）
- 整个 `weavelay-tools` 目录
- 本说明

客户包只需便携目录（JRE、模型、程序），授权走导入文件。
